# curveon-data

Offline search indexes for [Curveon](https://github.com/atlehavik/curveon), the motorcycle
dashboard app: one SQLite file per country (or US state, Canadian province, Russian federal
district) with places, useful POIs (fuel, cafés, viewpoints, campsites, …), streets with house
numbers and fixed speed cameras. The tablet downloads the one for each country it has a map of.

Built monthly by the GitHub Action in `.github/workflows/search.yml` from the
[Geofabrik](https://download.geofabrik.de/) OpenStreetMap extracts and published as assets of the
[`search` release](../../releases/tag/search), with `index.json` listing what's there.

Data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), available under the
Open Database License (ODbL).

- `areas.json`: area id → Geofabrik extract(s); generated by Curveon's
  `tools/search/geofabrik_areas.py` from its country catalog.
- `build_search_index.py`: copy of Curveon's `tools/search/build_search_index.py`.
- Rebuild some areas by hand: Actions → Search indexes → Run workflow, with a comma-separated
  list of area ids (or `all`).
