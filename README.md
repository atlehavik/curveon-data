# curveon-data

Offline search indexes for [Curveon](https://github.com/atlehavik/curveon), the motorcycle
dashboard app: one SQLite file per country (or US state, Canadian province, Russian federal
district) with places, useful POIs (fuel, cafés, viewpoints, campsites, …), businesses, streets
with house numbers and fixed speed cameras. The tablet downloads the one for each country it has a map of.

Built monthly by the GitHub Action in `.github/workflows/search.yml` from the
[Geofabrik](https://download.geofabrik.de/) OpenStreetMap extracts, plus businesses from
[Overture Maps](https://overturemaps.org/)' places dataset, and published as assets of the
[`search` release](../../releases/tag/search), with `index.json` listing what's there.

Data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), available under the
Open Database License (ODbL). Places from [Overture Maps Foundation](https://overturemaps.org/),
under [CDLA-Permissive-2.0](https://cdla.dev/permissive-2-0/) (and ODbL where they come from OSM).

- `areas.json`: area id → Geofabrik extract(s); generated by Curveon's
  `tools/search/geofabrik_areas.py` from its country catalog.
- `build_search_index.py`: copy of Curveon's `tools/search/build_search_index.py`.
- Rebuild some areas by hand: Actions → Search indexes → Run workflow, with a comma-separated
  list of area ids (or `all`).

## Speed limits

Official speed limits per country, for the speed sign: one small SQLite file each, built monthly by
`.github/workflows/speedlimits.yml` (`build_speedlimits.py`, a copy of Curveon's
`tools/speedlimits/build_speedlimits.py`) and published as assets of the
[`speedlimits` release](../../releases/tag/speedlimits), with `index.json` listing them. Curveon
uses them where present and OpenStreetMap's `maxspeed` elsewhere.

| Area | Source | Licence |
|---|---|---|
| norway | Statens vegvesen, NVDB (Fartsgrense), public roads | [NLOD 2.0](https://data.norge.no/nlod/no/2.0) |
| finland | Väylävirasto, Digiroad (dr_nopeusrajoitus) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| netherlands | NDW / Rijkswaterstaat, Wegkenmerkendatabase (Maximum snelheden) | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |
| belgium | Flanders only. Bron: MOW - AWV, Afgeleide snelheidsregimes | Modellicentie Gratis Hergebruik v1.0 |

Not yet: Sweden (Trafikverket's NVDB is CC0, but its API needs a registered key), Denmark
(Vejdirektoratet publishes state roads only).
